// philosophy

A kestrel doesn't chase. It holds altitude, and waits for the moment to be unmistakable.

Most tools built for trading are built to be busy — more signals, more noise, more reasons to act. Kestrel is built to be still.

It reads the same six charts all session, against the sense of normal it formed at the open — not one it re-guesses every time the price twitches. It waits, the way a kestrel hovers on a headwind: motionless except for what actually needs to move.

When something changes enough to matter, you hear about it. When it doesn't, you hear nothing at all — which is, most of the time, the more useful message.
